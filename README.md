### iReporter

iReporter Reader je jednoduchá webová aplikace, která umožňuje uživatelům sledovat aktuální zprávy a články z různých sekcí českých zpravodajských portálů. Uživatelé mohou snadno přepínat mezi různými tématy, jako jsou sport, věda a technologie, nebo hlavní zprávy. 

### Hlavní funkce:
- **Dynamické načítání článků:** Aplikace načítá RSS feedy v reálném čase pomocí Fetch API a zobrazuje články přímo na stránce.
- **Interaktivní tlačítka:** Uživatelé mohou vybírat mezi různými kategoriemi zpráv kliknutím na příslušná tlačítka. Každé tlačítko aktualizuje zdroj RSS a mění název sekce.
- **Automatická aktualizace:** Aplikace automaticky aktualizuje obsah každých 5 minut, takže uživatelé mají vždy přístup k nejnovějším informacím.
- **Přehledné zobrazení:** Články jsou zobrazeny v přehledném formátu s názvem, popisem a případným obrázkem.

### Použití
Po spuštění aplikace uživatelé vidí výchozí kanál (Sport) a mohou přepínat mezi různými tématy. Kliknutím na článek se otevře odkaz na původní zdroj.

### Technologie
- **HTML/CSS:** Pro strukturu a styl aplikace.
- **JavaScript:** Pro interaktivitu a dynamické načítání dat.
- **Fetch API a DOMParser:** Pro zpracování a zobrazení RSS feedů.

### Instalace
Pro spuštění aplikace stačí stáhnout zdrojový kód a otevřít soubor `index.html` v libovolném webovém prohlížeči.

### Přispívání
Příspěvky a návrhy jsou vítány. Vytvořte pull request nebo otevřete issue pro návrhy na vylepšení.

Tato aplikace je ideální pro ty, kteří chtějí mít přehled o aktuálním dění v různých oblastech a snadno přístup k nejnovějším článkům z českých zpravodajských médií.
